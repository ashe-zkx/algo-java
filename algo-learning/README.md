# algo-test

## 模块说明

本模块是一个**聚合模块**，包含多个测试和实验性质的子模块，用于学习和实践各种技术。

## 模块结构

```
algo-test/
├── pom.xml
├── README.md
├── algo-thread/         # 线程与并发编程
├── algo-raft/           # Raft 一致性算法
├── algo-serializable/   # 序列化实验
└── algo-rpc/            # 简单 RPC 框架
```

## 子模块概览

### 1. algo-thread
线程和并发编程相关的实现和示例。

**功能**：
- 多线程同步与协调
- 并发编程实践
- 性能对比测试

### 2. algo-raft
Raft 分布式一致性算法的实现。

**功能**：
- Raft 算法核心概念实现
- 分布式系统学习

### 3. algo-serializable
序列化相关的功能和实验。

**功能**：
- Thrift 序列化测试
- 其他序列化方案对比

### 4. algo-rpc
简单的 RPC（远程过程调用）框架实现。

**功能**：
- 基于 Socket 的 RPC 通信
- 服务注册与发现
- 动态代理实现

## 依赖关系

本模块作为父模块，统一管理子模块的构建配置。子模块根据各自需求引入不同的依赖。

## 使用说明

本模块主要用于学习和实验，每个子模块都可以独立运行和测试。详细使用方式请参考各子模块的 README.md。

## 优化建议

1. **模块命名**：当前模块命名为 `algo-test`，但实际上包含的不仅是测试代码，还有完整的功能实现
   - **建议**：考虑重命名为 `algo-practice` 或 `algo-learning`，更准确反映模块用途
   
2. **模块位置**：当前作为独立的一级模块，结构合理

3. **职责划分**：
   - **algo-thread** 和 **algo-rpc** 包含完整的功能实现，可以考虑移到独立的一级模块
   - **algo-raft** 和 **algo-serializable** 更偏向实验性质，适合保留在当前位置

4. **依赖优化**：各子模块依赖管理清晰，无需调整
