# algo-leetcode

## 模块说明

本模块用于 **LeetCode 刷题练习**，按难度分类存储算法题解。

## 模块位置

```
algo-leetcode/
└── src/main/java/pers/zkx/algo/leetcode/
    ├── simple/         # 简单难度题目
    ├── mid/            # 中等难度题目
    ├── hard/           # 困难难度题目
    └── week/           # 周赛题目
```

## 功能特点

- **按难度分类**：题目按 LeetCode 难度分为 simple、mid、hard 三个包
- **周赛专区**：week 目录存放周赛题目，便于集中练习
- **题解命名**：文件名通常为 `Solution{题号}.java`，便于查找

## 代码统计

- 包含约 59 个 Java 源文件
- 涵盖简单、中等、困难各类题目

## 依赖关系

本模块没有外部依赖，仅包含算法题解代码。

## 使用说明

1. 每个题目通常包含一个或多个解法
2. 类名通常以 `Solution` 开头，后跟题号
3. 部分题目可能包含多种解法和优化版本

## 注意事项

- **Java 版本要求**：代码使用了 Java 21 特性（如 `List.getFirst()`, `List.getLast()`）
- 建议使用 Java 21 或更高版本编译运行
